Detailed Description

Exception thrown when attempting to access an unregistered component type.

This error occurs when you try to get, add, or remove a component type that hasn't been registered with Registry::registerComponent<T>()

Example:

Registry reg;
// Forgot to call reg.registerComponent<Position>()
auto pos = reg.getComponents<Position>(); // Throws TypeNotRegistred
