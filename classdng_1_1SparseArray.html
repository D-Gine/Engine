Detailed Description

template<class Component>
class dng::SparseArray< Component >

Sparse Array implementation for the ECS.

Useful to manage a large amount of components associated with indexs as entities in an Entity Component System type of architecture. This class inherite from the std::vector and use std::optional type as variables wich makes it easier to access

std::vector<std::optional<Component>>
